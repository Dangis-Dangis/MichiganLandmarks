# About

**Michigan Landmarks** is an independent hobby project: an offline-first Android app (and local browser preview) for public Michigan landmark data. It is not affiliated with, endorsed by, or operated by the Michigan DNR, Michigan History Center, National Park Service, or the State of Michigan.
