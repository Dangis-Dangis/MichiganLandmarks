# Getting started

You are looking at a map of Michigan landmarks bundled in the app. There is no account and no project server.

## The header

![Header controls](assets/chrome.svg)

From left to right:

1. **Filters** — categories, sort, photo-only, hide city/township pins. [Open Filters](app:filters).
2. **Search** — filters the bundled list by name, county, and summary. It does not geocode. [Focus search](app:search).
3. **Near me** — uses on-device location to sort by distance and center the map. [Near me](app:locate).
4. **Help** — this overlay.
5. **List / Map** — switch between the map and a scrollable list. [Show list](app:list) · [Show map](app:map).

## Browse a landmark

1. Stay on the [map](app:map) or switch to the [list](app:list).
2. Tap a pin or a list row.
3. The detail sheet shows the name, category, description or plaque text, and links.
4. Scroll the sheet (or drag the handle up) for photos, maps actions, and sources.

## Go somewhere

On a detail card, **Open in Maps** and **Directions** hand off to Google Maps (or the device maps app). Those queries are not stored by this project. Always confirm hours and access on the official website when one is listed.

## Offline

Landmark text and the map library are bundled. Basemap tiles and photos need a network. See [Using the app](using-the-app.md#offline-and-network) and the diagram there.
